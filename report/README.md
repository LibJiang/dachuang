# 设计报告与协作记录

> 本目录放**最终交付物**；过程留痕放 `report/llm_log/`，两者不混。

---

## 报告结构（建议）

1. **项目背景**：PQC、HQC、NIST 标准化、为什么做硬件加速。
2. **国内外现状**：HQC 硬件实现、田静组 SOCC 2023 论文、SOTA 对比。
3. **算法分析**：参数、KEM 流程、码结构、瓶颈。
4. **架构设计**：PS/PL 划分、稀疏乘法、FHT、AXI/BRAM。
5. **验证方法**：C 黄金、xsim、KAT、负向、上板。
6. **实验结果**：资源、时序、延迟、加速比、Pareto。
7. **原创性说明**：贡献边界表、与基线差异。
8. **风险与未完成项**：明确标注。
9. **复现指南**：命令、版本、SHA256。
10. **参考**：官方 spec、参考实现、论文 DOI。

---

## 规则

- 所有数字必须有 `data/logs/` 或 `data/evidence/` 证据；
- 仿真 / 综合 / 上板分开写，不得混用；
- 复现内容与原创内容分开写；
- 未完成项不得写成“已完成”。
