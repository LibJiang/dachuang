# LLM 协作记录

> 目的：记录 AI 参与的关键决策、理解门槛、踩坑，方便复盘与答辩。
> 不记录：密钥、个人隐私、大段生成的代码（代码在 git 里）。

---

## 命名

```text
report/llm_log/YYYY-MM-DD-<主题>.md
```

## 必填

1. **任务**：这次让 AI 做了什么；
2. **输入**：参考的文档 / 论文 / 代码路径；
3. **决策**：AI 给了哪些选项，为什么选这个；
4. **理解门槛**：你能否不看代码讲清每个模块；不能的部分记下来；
5. **验证**：你亲自复现的命令与结果（不能只信 AI 说“完成”）；
6. **未完成 / 风险**：明确标注。

## 规则

- AI 产出必须经过你本人复现 + 理解，才能 commit；
- 不把 AI 生成的内容直接当“原创”；
- 引用外部代码/论文必须注明来源。
