# 协作纪录目录（docs/records）

每次完成一次可交付工作后，在这里写一篇协作纪录。

## 怎么用

1. 复制 `TEMPLATE.md`
2. 重命名为 `YYYY-MM-DD-成员名-主题.md`
3. 按模板填写，必须有可复现的验证证据
4. 和本次代码 / 文档放在同一分支 / 同一个 PR 提交

规范与强约束见：`docs/06_协作纪录与技能提炼规范.md`

## 命名示例

- `2026-11-05-zhangsan-montgomery-modmul.md`
- `2026-11-06-lisi-git-pr-flow.md`
- `2026-11-08-wangwu-ntt-butterfly.md`
