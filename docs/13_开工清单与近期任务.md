- RTL 线只由骆弈宾、曹子墨写；江力博/房煦然只做系统、验证、契约、验收。
- 只有江力博的机器有 Vivado：他是平台 owner；其他人用 iverilog/Verilator 预检。
- 江力博与房煦然共同维护 `plan.md` / `README.md` / `docs/`，两人都要了解全项目。
- 每周五集成；没有证据不算完成。
