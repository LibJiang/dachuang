# 基础补齐清单（只学过数电 + 信号与系统）

> 适用：本仓库全体本科生。
> 现状假设：**只系统学过“数字电路”和“信号与系统”**；没有 Verilog/FPGA 工程经验、没有 C/C++ 项目经验、没有密码学/编码理论/ASIC 流程基础。
> 目标：用 6 周补齐“能开工”的最低底座，不追求学完所有理论。
> 配套：`docs/03_前置知识与学习路线.md`、`docs/05_前置知识补全_从数电到Verilog实战.md`、`docs/09_工程约束与验证规范.md`。

---

## 一、先明确：你们已经有什么

| 已学 | 能直接用的地方 |
|:---|:---|
| 数字电路 | 组合/时序逻辑、状态机、触发器、建立/保持时间的概念 |
| 信号与系统 | 卷积、频域、变换的直觉；对 FHT/循环卷积有帮助 |
| 数学基础 | 微积分、线性代数（通常） |

**优势**：数电让你能理解“电路”，信号与系统让你能理解“卷积/变换”。HQC 的 dense×sparse 乘法本质是**循环卷积**，RM 解码本质是 **Hadamard 变换**，这两块你们有直觉。

**缺口**：从“会做题”到“能写可综合 RTL、能跑 Vivado、能对拍 KAT”，中间还差工程能力和密码/编码基础。

## 四、6 周补齐计划（每周 15–20 小时）

### 第 1 周：Verilog + Vivado + Git/WSL

- HDLBits：Combinational + Sequential 基础题；
- 手写 `counter`、`fsm`、`gf2_shift_xor` 三个小模块；
- 每个模块配自检 tb，`sim/run.ps1 rtl <tb>` 输出 `PASS`；
- 学 Git：clone、branch、commit、push、PR；
- **验收**：能独立跑通一次 xsim + Vivado 综合。

### 第 2 周：C/C++ + Python + 黄金模型

- C11 基础：指针、数组、位运算、文件读写；
- 编译并运行 `models/golden`、`models/kem/harness`；
- 用 Python/C 写一个小的向量生成器；
- **验收**：`qc_mult_ref --selftest` 与 KAT `PASS` 能复现；能提一个 PR。

### 第 3 周：GF(2) / 多项式环 / 循环卷积

- GF(2) 加法=XOR、乘法=AND；
- 多项式环 GF(2)[X]/(X^n−1)；
- 手算小例子：`a=0x4D, pos={1,4}`，验证结果 `0x4E`；
- 用 C 实现 dense×sparse 乘法，和仓库黄金对拍；
- 理解低延迟手段：LANES、BRAM banking、地址偏移/桶形移位、流水线 XOR；
- **验收**：1000 组随机 0 mismatch；能解释“为什么 dense×sparse 是 HQC 主方案，Karatsuba 只是老师举例”。

### 第 4 周：编码理论：RS / RM / FHT

- 线性码、生成矩阵、汉明距离、伴随式；
- RS：GF(2^8)、BM、Chien、Forney（先看流程，不啃证明）；
- RM(1,7)：128 点 FHT 解码；
- 用 Python/C 写一个小 RM FHT 解码器，和官方向量对拍；
- **验收**：能讲清“为什么 RM 可以用 FHT 解码”。

### 第 5 周：数字 IC 时序 + 体系结构

- setup/hold、关键路径、流水线、CDC；
- BRAM 读写、双口/乒乓、AXI-Lite 寄存器；
- 读 SOCC 2023，画出乘法/解码/存储数据流；
- **验收**：能解释“为什么要打拍”“异步 FIFO 解决什么”。

### 第 6 周：ASIC 流程 + 设计空间

- RTL → 综合 → 门级网表；标准单元、STA、area/power/fmax；
- PDK/库的作用；为什么 Vivado 不能做 ASIC；
- 读 Kyber 可配置乘法器/AC-PM，列出可参数化维度；Karatsuba/Toom-Cook 仅为示例；
- **验收**：能解释 LUT 与门级面积的区别；能画出一个 Pareto 轴。
