# IP 工程化交付清单

> 目标：把 HQC-128 KEM 从“能仿真的 RTL”做成**可交付、可集成、可复现的 IP 工程**。
> 优先级：**完整 IP 工程第一；ASIC 多工艺综合保留为主要差异点；ASIC 后端（P&R/STA）有余力再做，不流片、不阻塞 IP 交付。**
> 适用：`feat/hqc-fpga-asic` 集成分支；每个模块冻结后按本清单补齐。
> 配套：`README.md`、`plan.md`、`docs/12_FPGA_ASIC路线.md`、`docs/14_总体工作计划.md`。

---

## 一、什么叫“完整 IP 工程”

不是“RTL 能跑通”就结束，而是别人拿到仓库后能：

1. 看懂 IP 边界、接口、寄存器、时序和限制；
2. 用仓库内命令复现仿真、KAT、综合和板端结果；
3. 把 IP 集成到自己的 FPGA/SoC 工程；
4. 用驱动/裸机示例完成一次 KeyGen/Encaps/Decaps；
5. 查到每个结论的证据、版本和已知问题。

因此，IP 工程 = **RTL + 验证 + 软件接口 + FPGA 参考设计 + 文档 + release + 证据链**。

## 二、交付物清单

### 1. RTL 与集成

- [ ] 参数化 RTL：`N`、`LANES`、`SHIFT_IMPL` 等参数有默认值和约束说明；
- [ ] `filelist.f` / Vivado 工程文件 / 综合脚本；
- [ ] 顶层接口文档：时钟、复位、AXI4-Lite、BRAM、中断、错误码；
- [ ] 寄存器映射表：地址、位域、读写属性、复位值、副作用；
- [ ] 时钟/复位方案：同步复位、跨时钟域（如 SHAKE 低频/高频）说明；
- [ ] lint / CDC / 综合警告清理记录；
- [ ] 核心 RTL 不依赖 FPGA 原语；FPGA 封装放 `src/soc/` 或 `board/`。

### 2. 验证与证据

- [ ] 模块 testbench + 自检 `PASS/FAIL`；
- [ ] 官方 KAT 100/100（pk/sk/ss）+ 原始日志；
- [ ] 随机回归：乘法 1000 组、SHAKE/采样/RS/RM 官方向量；
- [ ] 负向测试：篡改密文 → 隐式拒绝；
- [ ] 恒定时间评估：FO 比较、采样、解码、位置访问；
- [ ] 系统仿真 0 mismatch；
- [ ] 证据路径：`data/logs/`、`data/evidence/`、`report/llm_log/`。

### 3. 软件接口

- [ ] AXI4-Lite 驱动（C/C++ 或 Python）；
- [ ] 裸机示例：KeyGen → Encaps → Decaps → KAT 对拍；
- [ ] 寄存器读写示例、错误处理、超时；
- [ ] 与官方 KAT 的字节序/数据格式说明；
- [ ] 驱动不依赖特定 OS；Artix-7 无 PS 时走 UART/JTAG/AXI。

### 4. FPGA 参考设计

- [ ] AC701 XC7A200T 参考工程（主）；XC7A100T（备）说明；
- [ ] 约束文件：时钟、I/O、时序例外；
- [ ] bit/hwh + 板端下载说明；
- [ ] 板端 KAT 100/100 日志；
- [ ] 资源/时序/周期报告：LUT/FF/BRAM/Fmax/cycles；
- [ ] 板卡接线、UART/JTAG 使用说明。

### 5. ASIC 前端与可选后端

- [ ] 55nm 主 / 28nm 对比 / 90nm 兜底综合脚本；
- [ ] area/power/fmax 报告；与 FPGA 对照；
- [ ] ASIC 导向检查：无 FPGA 原语、无 `initial` 初值、无 `#delay`；
- [ ] 可选后端：P&R、STA、功耗、DRC/LVS 报告；
- [ ] 后端不流片；工具/PDK/收敛不满足时停在综合，并写降级说明。

### 6. 文档与 release

- [ ] `README`：IP 一句话、特性、限制、快速开始；
- [ ] 集成指南：端口、寄存器、时钟、复位、数据流；
- [ ] 寄存器手册；
- [ ] KAT/验证报告；
- [ ] PPA/设计空间报告；
- [ ] 已知问题与限制（known issues）；
- [ ] release 包：版本号、changelog、许可证、第三方声明；
- [ ] 一键复现脚本：`run_sim`、`run_kat`、`run_synth`、`run_board`；
- [ ] 版本 tag（如 `v0.1-hqc128`）。

## 三、验收标准

| 类别 | 通过标准 |
|:---|:---|
| 功能 | 官方 KAT 100/100；系统仿真 0 mismatch；隐式拒绝正确 |
| 集成 | 第三方按集成指南可在 1 天内跑通仿真；寄存器读写正确 |
| 软件 | 裸机示例完成 KeyGen/Encaps/Decaps，并能对 KAT |
| FPGA | 板端 KAT 100/100；PPA 报告完整 |
| ASIC | 55/28/90nm 综合报告；后端可选，不阻塞验收 |
| 复现 | 仓库内命令可生成上述证据；release 包可下载/可构建 |
| 文档 | 无“未实现/未验证”被写成“已完成”；限制写清楚 |

## 六、风险与停止条件

| 风险 | 应对 |
|:---|:---|
| IP 打包拖慢 RTL | IP 清单从 M1 开始并行做，不等到最后 |
| ASIC 后端时间不可控 | 后端只作可选拔高；工具/PDK/收敛任一不满足就停在综合 |
| 文档与实现不一致 | 接口/寄存器变更必须三处同步：RTL、tb/驱动、契约/文档 |
| release 不可复现 | 每个 release 必须附一键脚本和证据路径 |
| 范围膨胀 | HQC-128 先行；192/256、RISC-V、后端均为可选，不阻塞 V0/V1 |

**停止条件（后端）**：没有可用工具/PDK、P&R 不收敛、STA 无法签收、时间不足 → 记录现状，停止后端，保留综合报告。
