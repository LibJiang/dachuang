## 二、研究方向拆解

### 1. 后量子密码硬件（主战场）

- **算法对象**：Kyber / ML-KEM、Dilithium / ML-DSA、SPHINCS+ / SLH-DSA、Classic McEliece、HQC、SIKE、Scloud+
- **核心运算**：NTT / INTT、多项式乘法、模约减、采样器、Keccak / Haraka 哈希
- **硬件目标**：更小的面积、更短的关键路径、更高的吞吐、更低的功耗
- **代表工作**：Kyber 多项式乘法加速器、HRCIM-NTT、Fast Scloud+、McEliece KeyGen

### 2. AI 同态安全（FHE / 隐私计算）

- FHE（BFV / BGV / CKKS / TFHE）加速器
- 同态卷积、矩阵-向量乘法（LEAM）
- 隐私推理（MPC / TEE）、同态神经网络
- 代表工作：Efficient Homomorphic Convolution on FPGA、LEAM、Lagrange Coded Computing

### 3. 区块链硬件

- SHA-256 / Keccak 高吞吐哈希
- ECDSA / Schnorr
- zkSNARK 中的 MSM / NTT 加速
- 与后量子签名、VDF 等方向交叉

### 4. 现代纠错码

- RS / BCH / LDPC / NB-LDPC 译码器 VLSI
- ORBGRAND 等 GRAND 类通用译码
- 服务于存储、光通信与 PQC 容错
- 这是田老师博士阶段的核心根基

> 一句话总结：**"为密码学与编码理论里最耗算力的算法，设计更快更省的数字集成电路。"**

## 六、两篇入门论文（只有数电基础也能读）

### 第 1 篇（首推，最容易讲）

**High-Speed and Low-Complexity Modular Reduction Design for CRYSTALS-Kyber**（APCCAS 2022）
<https://doi.org/10.1109/apccas55924.2022.10090253>

- **为什么选它**：整篇核心是**模约减**——把大数对 q=3329 取模，用移位、加法、比较、多路选择器实现，不需要深入密码学。
- **论文做了什么**：用**有符号数表示**缩小位宽，用自研 **Fast LUT（FLUT）** 代替大 ROM 和除法，再用 **K-RED**（利用 q = 13·2⁸ + 1）把大数压小；结果是 FPGA 资源约少 25%、关键路径约短 25%、延迟仅 2 个时钟周期。
- **最巧妙的一点**：约减引入的常数恰好等于 INTT 本就要乘的 `(N/2)⁻¹`，因此顺手把 INTT 的"除以 N/2"也省掉了。
- **怎么读**：跳过数学证明，只看架构框图、数据通路、关键路径和 PPA 对比表。

### 第 2 篇（讲"架构"的门面）

**AC-PM: An Area-Efficient and Configurable Polynomial Multiplier for Lattice Based Cryptography**（TCAS-I 2023）
<https://doi.org/10.1109/tcsi.2022.3218192>

- **为什么选它**：核心是**多项式乘法器**，本质是一堆乘法器 + 加法树 + 寄存器堆 + 可配置控制。
- **关注点**：数据怎么流动、为什么这样切分能省面积、PPA 对比表。

### 进组面试可以直接说

> "我数电基础扎实，读了田老师组 Kyber 模约减和多项式乘法器两篇，能看懂数据通路和 PPA 取舍，想在密码芯片的算术单元 / 架构优化方向入手。"
