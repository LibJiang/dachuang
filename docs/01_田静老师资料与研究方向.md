## 二、研究方向拆解

### 1. 后量子密码硬件（主战场）

- **算法对象**：Kyber / ML-KEM、Dilithium / ML-DSA、SPHINCS+ / SLH-DSA、Classic McEliece、HQC、SIKE、Scloud+
- **核心运算**：NTT / INTT、多项式乘法、模约减、采样器、Keccak / Haraka 哈希
- **硬件目标**：更小的面积、更短的关键路径、更高的吞吐、更低的功耗
- **代表工作**：Kyber 多项式乘法加速器、HRCIM-NTT、Fast Scloud+、McEliece KeyGen

### 2. AI 同态安全（FHE / 隐私计算）

- FHE（BFV / BGV / CKKS / TFHE）加速器
- 同态卷积、矩阵-向量乘法（LEAM）
- 隐私推理（MPC / TEE）、同态神经网络
- 代表工作：Efficient Homomorphic Convolution on FPGA、LEAM、Lagrange Coded Computing

### 3. 区块链硬件

- SHA-256 / Keccak 高吞吐哈希
- ECDSA / Schnorr
- zkSNARK 中的 MSM / NTT 加速
- 与后量子签名、VDF 等方向交叉

### 4. 现代纠错码

- RS / BCH / LDPC / NB-LDPC 译码器 VLSI
- ORBGRAND 等 GRAND 类通用译码
- 服务于存储、光通信与 PQC 容错
- 这是田老师博士阶段的核心根基

> 一句话总结：**"为密码学与编码理论里最耗算力的算法，设计更快更省的数字集成电路。"**

## 五、进组阅读顺序建议（HQC 方向）

1. **先读 15**：SOCC 2023 的 HQC 硬件实现——这是本项目最直接的技术基线。
2. **再读 22–30**：RS / BCH / LDPC / ORBGRAND 等纠错码工作——HQC 的码基础。
3. **然后 1、2**：Kyber 多项式乘法 / 可配置乘法器——方法论参考，不是 HQC 的直接实现。
4. **补 4、5**：侧信道防护与攻击——组里的安全实现方向。
5. **再看 6**：Kyber 模约减——学习“算法性质 → 硬件结构”的写法，FLUT+KRED 不直接用于 HQC。
6. **其他方向（7–14、16–21、31–33）按需**：SIKE、McEliece、同态、AI 加速，作为背景。

## 六、两篇入门论文（只有数电基础也能读）

### 第 1 篇（首推，直接基线）

**An Efficient Hardware Design for Fast Implementation of HQC**（SOCC 2023）
<https://doi.org/10.1109/socc58585.2023.10257054>

- **为什么选它**：这是田老师组直接做 HQC 硬件的工作，和你的大创方向完全对口。
- **论文关注什么**：HQC 的乘法/解码怎么映射到硬件、数据怎么流、存储怎么放、PPA 怎么取舍。
- **怎么读**：先看摘要、架构图、数据流和 PPA 对比表；数学细节和证明先跳过，具体实现以原文为准。
- **读完要能做到**：说出它用了什么架构、瓶颈在哪、你的“RISC-V 集成/设计空间/混合协同”与它的差异是什么。
- **重要**：该文已经做了**稀疏乘法、RM FHT、RS ePIBM、完整 HQC-128 KEM**；这四项不能当你的原创。差异表见 `docs/11`。

### 第 2 篇（方法论参考）

**High-Speed and Low-Complexity Modular Reduction Design for CRYSTALS-Kyber**（APCCAS 2022）
<https://doi.org/10.1109/apccas55924.2022.10090253>

- **为什么读它**：它把“利用算法特殊性质简化硬件”讲得很清楚——Kyber 利用 q = 13·2⁸ + 1 做 K-RED/FLUT；HQC 则利用 GF(2) 和固定重量稀疏结构。
- **怎么读**：跳过数学证明，只看架构框图、数据通路、关键路径和 PPA 对比表。
- **注意**：FLUT+KRED **不能直接搬到 HQC**；你要学的是“从算法性质找硬件简化”的方法，而不是抄电路。

### 进组面试可以直接说

> "我数电基础扎实，读了组里 SOCC 2023 的 HQC 硬件和 APCCAS 2022 的模约减，能把算法结构映射到数据通路和 PPA。想在 HQC 稀疏乘法、完整 KEM 软硬协同和 PPA 优化方向入手。"
