## 冻结流程

1. 作者提交草案，写清：端口、数据格式、时序、错误行为、验证方法。
2. 至少 1 名队友复核，确认与 C 黄金 / testbench 一致。
3. 状态改为 `冻结`，并在 `docs/records/` 写一条“契约冻结”纪录。
4. 后续改动：开新版本 `_v1.md`，旧版本保留，不得原地改语义。

## 通用约定

- 数据表示见 `docs/09_工程约束与验证规范.md` 第二节。
- 所有模块必须参数化 `N`、`W`、`LANES`，不得写死 HQC-128。
- 时序单位：时钟周期；延迟定义为 `start` 被接受后到 `done` 有效的周期数。
- 错误行为：非法参数/越界地址 → 置 `error`，不得静默截断。
