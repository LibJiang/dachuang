# 前置知识与学习路线（面向田静组 / 密码硬件方向）

> 目标：从"只学过数电"成长到"能写可综合 Verilog、看得懂 PQC 硬件论文、会看 PPA"。
> 核心能力模型：**能写 Verilog + 能综合出电路 + 看得懂密码算法 + 会看 PPA**。
> 建议投入：每周 15~20 小时，6 个月为一个周期。
>
> **配套文档**：如果"学过数电但还没写过 Verilog"，先看 [`05_前置知识补全_从数电到Verilog实战.md`](05_前置知识补全_从数电到Verilog实战.md)——它把工程基础、四周动手计划和可复用的旧仓库资产讲得更细。

| 模块 | 必须掌握 | 优先级 |

## 五、第一个动手项目（强推，进组"投名状"）

**用 Verilog 复现论文《High-Speed and Low-Complexity Modular Reduction Design for CRYSTALS-Kyber》的模约减模块。**

步骤：

1. 用 Python 建参考模型：输入 `c ∈ (-2²⁴, 2²⁴)`，输出 `r ≡ (N/2)⁻¹·c (mod 3329)`。
2. 实现 K-RED 段：`r = d1 − 13·d0`，其中 `13 = 2³ + 2² + 1`，用移位加法代替乘法。
3. 实现 FLUT 段：`T_out = u[5:0]·59 + u[6]·3329`，其中 `59 = 2⁶ − 2² − 1`。
4. 写 Testbench，用大量随机向量与边界值验证。
5. Vivado 综合，记录 LUT / FF / DSP / 关键路径 / 延迟，和论文表 I 对比。

做完后可以这样联系导师：

> "我复现了您组 APCCAS 2022 的 Kyber 模约减模块，用移位加减实现 FLUT 与 K-RED，综合结果与论文基本吻合 / 在某某指标上更优，想在密码芯片算术单元方向继续深入。"

## 七、避坑提醒

1. **别先啃抽象代数和格密码证明**——会劝退，且组里做的是硬件不是理论。
2. **别只看视频不动手**——Verilog 必须写，HDLBits 比看十门课有用。
3. **别贪多**——先"Verilog + 模运算 + NTT 硬件"这三样，其他边做边补。
4. **中文优先**——中国大学 MOOC 的 Verilog / 数电课足够入门，别一上来啃英文教材。
5. **每写一个模块都要有测试平台**，否则后期调试成本极高。
6. **代码与实验数据尽早进 Git**（就是本仓库），养成版本管理习惯。
