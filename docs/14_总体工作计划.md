## 六、风险与应对

| 风险 | 应对 |
|:---|:---|
| RTL 工作量大 | 先 HQC-128；模块并行；M2 前不加 192/256 |
| KAT 对不上 | 官方参考；先 pk/sk/ss，再补 encaps ct |
| ASIC 工具缺失 | 降级为“ASIC 导向 RTL + FPGA PPA”，不伪造数据 |
| 只有江力博有 Vivado | 周五批处理；第二人装免费 Vivado BASIC 兜底 |
| **FPGA 全功能跑通难** | AC701 200T 主；预留 4–6 周 bring-up；先仿真后上板 |
| **板卡借用冲突** | 备选 100T / 常州 200T；P0 预约 P3 窗口 |
| **国家级原创性弱** | ASIC 多工艺 + 设计空间 + 参数化/开源；写差异表 |
| 接口反复变 | 契约冻结；PR 必须同步契约 |
| 老师时间难约 | 房煦然提前约；问题清单一次问清 |
